# DarijaDoc

Arabic/Darija Voice Medical Navigator for the GOMYCODE hackathon.

## Frontend

The React application lives in [`FrontEnd/`](FrontEnd/).

```sh
cd FrontEnd
npm install
npm run dev
```

For validation, run `npm test` and `npm run build` from `FrontEnd/`.
